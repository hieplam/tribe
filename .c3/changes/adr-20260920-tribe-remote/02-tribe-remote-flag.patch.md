A bare tribe starts the read-only viewer and opens the browser, modelled on kanna's CLI: --port (default 4321, 1-65535), --remote (kanna's shortcut for --host 0.0.0.0: reachable from every device on the local network, no password), --host <address>, --strict-port, --no-open, -v/--version (the plugin version), -h/--help; an unknown option or a missing --port/--host value refuses with one stderr line and exit 2. It probes the port through the runner's own /healthz reader (buildViewerPort + classifyProbe, one parser for that shape), at the address the viewer must be reachable on — a LAN address for --remote, so a localhost-only viewer on the port is not reused for a network request: a current tribe viewer is reused and nothing starts (exit 0); a free port starts serve.ts in the foreground, opens the browser once /healthz answers, forwards Ctrl-C and exits with the viewer's code (0 on a signal); a port held by anything else, or a serve.ts bind refusal (exit 1), moves to the next port for up to 20 ports, or refuses with exit 1 under --strict-port.
