# Coffee

Espresso ink on oat milk: a warm tan page, a crema panel, and a near-black roast for type, set like something printed rather than rendered. Square corners and a double rule under each label give it the most typographic, most "document" character of the three.

**Accent** — a cinnamon-espresso brown (`#8a4419` light, `#e3a26b` dark), chosen because it is the only one of the three accents that shares nothing with the status colours: green means live, red means failed, and brown means "you". Nothing a tool call can report will ever be mistaken for a link or an active tab.

**Bad at** — the warm brown accent sits close enough to the `--warn` amber that a running tool card and a link are not instantly separable in peripheral vision; the tan paper is the least neutral ground of the three for screenshots, and in dark mode the crema accent is light enough that a filled primary button reads as a bright chip on a very dark field.

**Measured** — body ink on paper: 15.18:1 light, 15.46:1 dark. Every text token clears 4.5:1 in both modes.
Open `preview.html` in any browser (no server needed) and use the toggle at the top right to force light or dark.
